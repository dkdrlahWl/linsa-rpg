# 코스튬 인게임 걷기 그림 다시 요청 (2026-10-25)

대상: 1천만·2천만·3천만 코스튬 18종
- 1천만: 태양장미 여제, 별다방 마도사, 극광 매사냥꾼, 월광보석 쌍검무희, 홍련 비공정 조종사, 오팔 꿈사제
- 2천만: 뇌전 사자 발키리, 빙정 서고의 마도사, 단풍 구미호 궁수, 흑익 가면 암살자, 심해 진주 해적, 황금 태양의 신탁자
- 3천만: 백조의 호수 기사, 천일야화 마도사, 비취 공작 궁수, 홍접 비단 무희, 설탕왕국 총사, 등꽃 성녀

문제: 걷기 그림이 정지 일러스트를 복사한 것(2천만)이거나, 발을 거의 안 떼거나 다리가 꼬여서 걸을 때 다리가 멈춰 보이거나 이상하게 교차해요. 그리고 기본 캐릭터보다 머리가 작은 3등신이라 인게임에서 머리 크기가 달라 보여요.

## 그림 한 장 = 코스튬 1종 (5 × 5 칸, 투명 배경)

- **비율: 기존 기본 캐릭터처럼 머리 큰 2등신(SD) 치비.** 머리가 키의 약 45%.
- 의상·색·무기는 상점 일러스트(코스튬 portrait)를 그대로 따라 그리기.
- 칸마다 캐릭터 한 명, 전신, 발끝까지, 칸끼리 겹치지 않게 넉넉한 여백.
- 서 있는 자세(앉거나 떠 있는 자세 금지). 치마·로브가 길어도 **발과 종아리가 보이게.**

| 행 | 내용 |
|---|---|
| 1행 | 가만히 서 있기 |
| 2행 | 걷기 A: **왼발 앞으로 크게 한 걸음**, 오른발 뒤. 두 다리가 확실히 벌어지고 교차하지 않게 |
| 3행 | 걷기 B: **오른발 앞으로 크게 한 걸음**, 왼발 뒤 (2행의 반대 발) |
| 4행 | 공격 준비 자세 |
| 5행 | 공격 동작 (무기 휘두르기·쏘기·마법 발사) |

| 열 | 방향 |
|---|---|
| 1열 | 정면 (화면 쪽) |
| 2열 | 정면 대각선 (오른쪽 아래) |
| 3열 | 옆 (오른쪽) |
| 4열 | 뒤 대각선 (오른쪽 위) |
| 5열 | 뒷모습 |

파일을 주면 `scripts/build-costume30m.py` 방식으로 인게임 모션 시트로 만들어 적용할게요(3천만 코스튬과 같은 방식).
