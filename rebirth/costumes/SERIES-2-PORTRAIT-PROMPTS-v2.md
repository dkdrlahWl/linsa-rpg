# Series 2 portrait generation

Method: built-in image_gen, style-transfer mode, transparent background.

For each portrait, reference image 1 was the matching original class portrait and
reference image 2 was the corresponding series 2 costume portrait v1. The common
prompt requested a single full-body 430×720-style Korean fantasy RPG shop
portrait with the original class portrait's painterly finish, proportions,
framing and detail, while preserving the new costume's identity, colors and
accessories. It specified a transparent cutout, visible torso, legs and boots,
and excluded UI, backgrounds, extra figures, duplicate limbs and battle-sprite
proportions.
