# 암흑성채 0단계 — 구현·검증 기준

기준일: 2026-10-10. 참고작은 **Heroes of Hammerwatch II**이다. Hammerwatch II와 다른 게임이다.

이번 구현은 링구 RPG의 기존 직업·장비·스킬을 사용하는 별도 탐험이다. 원작 실행 파일이나 내부 맵 데이터를 확보한 정밀 복제본으로 표현하지 않는다.

## 조사 출처

- [개발사 공식 소개](https://www.heroesofhammerwatch2.com/): 최대 4인 협동, 무작위 지역, NG+.
- [개발사 연결 위키 — Dark Citadel](https://wiki.heroesofhammerwatch2.com/index.php/Dark_Citadel): 주 경로 순서와 여섯 보스전.
- [Totem Pole](https://wiki.heroesofhammerwatch2.com/Totem_Pole): 원소별 단계.
- [Avatar](https://wiki.heroesofhammerwatch2.com/Avatar): 최종 보스 단계.
- [Beasts](https://wiki.heroesofhammerwatch2.com/Beasts), [Undead](https://wiki.heroesofhammerwatch2.com/Undead), [Aberrations](https://wiki.heroesofhammerwatch2.com/Aberrations): 적 종류 참고.

원작 공개 자료에는 카메라 내부 배율, 지도 전체 타일 수, 이동 단위/초, 모든 지도에서의 정확한 적 수가 명시되지 않는다. 아래 수치는 링구의 구현·밸런스 수치다. 원작과 수치가 같다고 확인한 것은 아니다.

## 캠페인

주 경로 21구역을 시작부터 마지막 보스까지 연결한다. 보스전은 5·10·13·16·19·21구역이다. 총 8가지 환경을 사용한다.

| 구간 | 지역 | 보스전 구성 |
|---|---|---|
| 1–5 | 숲·동굴 | 토템 1체, 네 원소 단계 |
| 6–10 | 숲·신전·묘지 | 직접 공격 불가, 의식 수행자 처치 |
| 11–13 | 감옥 | 식물 보스, 가시·독·소환 |
| 14–16 | 병영 | 근접·마법 전령 2체 |
| 17–19 | 왕실의 뜰 | 뱀 3체, 광선·불길·몸 충돌 |
| 20–21 | 암흑 회랑 | 이동 가능한 시야 차단 벽, 분열 적, 최종 3단계 |

일반 구역은 출구를 찾으면 다음 구역으로 이동할 수 있다. 보스 구역은 보스 처치가 필요하다. 일반 구역 15분, 보스 교전 시작 후 10분이다. 다음 구역에서 최대 체력의 20%를 회복한다. 사망한 동료 옆에서 5초 멈추면 부활한다. 마지막 승리에서 방장 열쇠 1개를 차감하며, 기존 개인 보상 상자 규칙을 사용한다.

원작의 마을 건설·NPC 구출·직업 해금·건축가 지름길·촛불 선택 구간·장비 및 스킬 전체 체계는 이 탐험에 이식하지 않았다. 링구의 기존 성장 체계를 사용한다. NG+1 이후 콘텐츠는 이번 범위 밖이다.

## 인원 규칙

| 출발 인원 | 몬스터 체력 | 공격력 |
|---|---:|---:|
| 1 | 1배 | 1배 |
| 2 | 2배 | 1배 |
| 3 | 3배 | 1배 |
| 4 | 4배 | 1배 |

소환 몬스터·의식 수행자·분열 몬스터도 체력 배율을 따른다. 출발 인원으로 고정하므로 중간 이탈이 난이도를 낮추지 않는다. 이 규칙은 사용자가 확정한 규칙이며 원작의 배율이라고 주장하지 않는다.

## 화면·맵·그래픽

지도는 64×64 타일, 타일당 100 전투 단위다. 숲·동굴은 넓고 자연스러운 방, 성채는 방·회랑, 암흑 회랑은 굽은 주 통로와 가지 통로를 사용한다. 동일한 기하를 서버·워커·충돌·미니맵에서 공유한다. 같은 시드는 같은 지도와 적 배치를 만든다.

화면은 위에서 내려다보는 픽셀 표현이며, 성채 캐릭터 크기는 기존 링구 전투의 40%다. 기존 탐험 카메라의 안정적인 줌과 이동속도 1.3배를 사용한다. 원작 화면의 작은 캐릭터와 넓은 시야를 참고했으나 실제 원작 엔진의 배율·속도와 일치한다고 측정한 것은 아니다.

새 지역 타일 8세트, 일반 적 이미지 32종, 보스 이미지 10종은 imagegen으로 만든 별도 에셋이다. 원작 이미지를 게임 에셋으로 사용하지 않았다. 출현 수는 일반 구역에서 `70 + 막 번호×12 + 시드 난수 0–19`이며 보스 소환은 최대 12체로 제한한다. 이것도 링구의 수치다.

## 도현 중반 기준

기준 전사: Lv.200, 공격력 49,108 / 체력 67,525 / 방어력 1,373 / 치명타 41% / 치명타 배율 1.6 / 보스 배율 3.2 / 전직 4. 실제 계정 상태·아이템·재화는 변경하지 않았다.

`citadel-balance.test.mjs`는 이 능력치로 적에게 접근하여 모든 공격 스킬을 사용하는 봇이다. 공격 예고를 적극적으로 회피하지 않으며, 보스방 시작 조건에서 테스트한다. 전체 캠페인의 인간 클리어 확률이나 실전 성공률을 추정하는 통계 실험은 아니다.

| 보스 구역 | 기준 봇 결과 |
|---:|---|
| 5 | 통과 |
| 10 | 통과 |
| 13 | 실패 |
| 16 | 실패 |
| 19 | 실패 |
| 21 | 실패 |

10/21구역까지 진행하는 중반 기준으로 조정했다. 회피 숙련·직업 조합·회복 지원·장비 성장으로 결과가 달라진다. 50% 성공 확률을 보장한다는 의미가 아니다.

## 검증과 한계

- 21구역×20시드: 시작·출구·모든 방 연결 검사.
- 21구역 전체 4인 전투: 이펙트·피해 숫자·위험 지대 상한 검사.
- 4인, 0.2–1.1초 지연·중복·순서 뒤바뀜 입력 및 재처리 검사.
- 실제 모듈 워커와 서버 전투 모델 일치 검사, 6개 모드×6직업.
- 기존 탐험·충돌·픽업·보상·열쇠·클리어 이후 이동 회귀 검사.

이 환경에서는 실제 브라우저 화면 및 서로 다른 기기 4대의 인터넷 연결 상태를 시험하지 못했다. 시뮬레이션 통과는 실제 기기에서 프레임 드롭·네트워크 끊김이 없다는 보장이 아니다. 원작과 모든 항목이 완전히 동일하거나 버그가 없다고 보증하지 않는다.
