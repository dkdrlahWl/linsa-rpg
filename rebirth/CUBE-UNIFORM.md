# 전 장비 공통 큐브

- 장비 레벨·직업·부위·일반/보스 여부에 따른 옵션 차이 없음. 모든 큐브가 동일한 등급별 옵션 표 사용.
- 장비 잠재 등급을 먼저 결정한 뒤, 세 줄 모두 그 등급에서 독립 추첨. 낮은 등급의 줄은 나오지 않음.
- 레드: 레어→에픽 6%, 에픽→유니크 1.8%, 유니크→레전더리 0.3%. 보장 시도 26/84/501회.
- 블랙: 30% / 7% / 2.8%. 보장 시도 11/43/108회. 기존/새 결과 선택.
- 프라임: 100% / 10.5% / 4.2%. 에픽·유니크 보장 시도 43/108회. 첫 줄 고정 없이 세 줄 즉시 재설정.
- 승급 실패 시 현재 장비 등급 유지. 레전더리에서 추가 승급 없음.
- 옵션 종류마다 동일한 확률. 같은 종류에 두 수치가 있는 보스 피해는 종류 확률을 35%·40%에 절반씩 배분.
- 레어: 15종류, 각각 약 6.666667%. 에픽: 8종류, 각각 12.5%. 유니크: 12종류, 각각 약 8.333333%. 레전더리: 10종류, 각각 10%.
- 레전더리 STR/DEX/INT/LUK 각 +12%, 공격력 +12%, HP +12%, 치명타 확률 +12%p, 고정 공격력 +32, 골드 획득 +20%는 각각 10%. 보스 피해 +35%·+40%는 각각 5%.
- STR +12% 3줄의 기본 생성 확률은 0.1%. 현재 결과와 등급·옵션·수치가 전부 같으면 재추첨하므로 최종 확률은 기존 결과 제외 조건부 확률. 이미 STR 12% 3줄이면 같은 결과는 다시 나오지 않음.
- 기존 장비 옵션과 진행 중인 블랙 선택 결과는 자동 재추첨하지 않음. 새로운 큐브 사용과 잠재 주문서 개방부터 적용. 주문서는 3줄 모두 레어.
- 기존 큐브별 보장 누적 횟수는 보존. 프라임 보장 횟수는 레드·블랙과 별도 누적.

실제 옵션 목록·수치는 universal-cube-pools.mjs, 승급·추첨은 maple-cubes.mjs. 게임 내 큐브 창과 probability-guide.html에서 동일한 공통 표를 표시.
