# 4인 탐험·레이드·성채 전송량 최적화 — 2026-10-14

## 바뀐 것 (`coop-wire.mjs`)

- **되감기 기록 압축 저장**: `_net.points`(전체 월드 사본 3~6개)를 현재 방과의 차이만 저장(`_net.packed`). SQL이 읽는 `_net.frames`는 그대로. 구버전 방(`points`)도 그대로 읽음.
- **predictionBase 차이 전송**: 응답마다 같은 월드가 두 번 들어가던 것을, 현재 방 대비 차이로 전송.
- **층 고정 데이터 캐시**: 지형·몬스터 이름/그림/능력치를 클라이언트가 보관하고, 서버는 클라이언트가 이미 가진 몬스터의 고정값은 생략. 몬스터가 죽어도 재전송 없음. 새 소환수만 전체 전송.
- 모든 압축은 클라이언트가 `wire:2`를 보낼 때만 적용 → 구버전 클라이언트/구버전 엣지와 서로 호환.
