# 스킬 외형 수집 칭호 4종

기존 칭호처럼 서버가 명령 처리 후 조건을 검사해 자동 지급한다. 이미 조건을 달성한 계정도 다음 동기화에서 획득하며, 중복 지급하지 않는다. 별도 구매나 새 저장 필드는 없다. 보유 효과는 기존 규칙인 칭호당 치명타 피해 +0.5%p이며 장착·해제로 추가 능력치가 생기지 않는다.

| ID | 칭호 | 등급 | 획득 조건 |
| --- | --- | --- | --- |
| look3 | 환상의 수집가 | 영웅 | 스킬 외형 3종 보유 |
| look6jobs | 여섯 빛의 조율자 | 전설 | 6직업의 스킬 외형을 각각 1종 이상 보유 |
| look9 | 별빛의 연출가 | 전설 | 스킬 외형 9종 보유 |
| look18 | 천상의 만화경 | 신화 | 스킬 외형 18종 전부 보유 |

내장 image_gen으로 투명 배경 명패 4장을 제작했다. `titles-src/plates/`의 WebP에 기존 Black Han Sans 글꼴과 SVG 글자·빛 흐름·반짝임 효과를 합성해 `titles/<id>.svg`로 배포한다. 기존 68개 원본 행과 칭호 이미지는 변경하지 않는다. 기존 수집 화면·장착·해제·랭킹·협동 로비 표시를 그대로 사용한다.

`titles-skill-collection.test.mjs`는 정확한 수집 경계, 6직업 조건, 잘못된 ID·중복 ID, 자동 지급 1회, 저장 복원, 잠긴 칭호 차단, 기본 보유 효과, 서버/클라이언트 정의와 내장 그림·글꼴을 검사한다.
