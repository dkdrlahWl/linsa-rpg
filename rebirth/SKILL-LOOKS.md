# 스킬 외형 상점

6직업별 3종, 총 18종. 각 20,000,000골드. 구매하면 영구 보유하고 해당 직업에서 장착·해제한다. 직업별 장착 선택은 각각 저장된다. 공격력 보너스가 없는 외형 전용 상품이다.

내장 image_gen으로 테마마다 투명 배경 시트 1장씩 제작했다. 각 시트는 1~5차별 그림과 발동·타격·잔광 3프레임으로 구성된다. 총 90개 스킬 디자인, 270개 이미지 프레임. `skill-looks/`의 WebP 시트 18개와 상품 미리보기 18개를 사용한다. 필요한 장착 테마만 전투 전에 불러온다.

`skill-looks.mjs`는 가격·소유·직업별 장착을 관리하고 `skill-look-effects.mjs`는 이미 존재하는 전투 이벤트를 그린다. 전투 데미지, 범위, 타수, 회복량, 판정, 쿨타임을 수정하지 않는다. 기본 공격과 적 공격도 유지한다. 1~5차 개인/협동 전투, 사제 보호막, 간략 전투, 아레나 효과를 연결했다. 협동 화면의 기존 개인 이펙트 표시 정책을 따른다. 해제하면 기존 아트가 사용된다.

기존 계정은 첫 명령에서 비어 있는 소유·장착 필드를 초기화한다. 서버의 기존 요청 영수증과 저장 경로를 사용하며 스키마 변경은 필요 없다. 운영 함수는 기존 인증·세션 처리를 보존하고 새로운 엔진/아레나 모듈로만 연결한다.

검증: `skill-looks.test.mjs`에서 18종의 정확한 골드 차감, 중복·잔액·미소유·타직업·전투중 차단, 직업 전환 및 저장 복원, 기본 대비 동일한 능력치, 18개 60초 전투 재생과 아레나 결과 동등성, 1~5차 프레임 배정 및 파일 존재를 확인한다. 기존 배포 워크플로 29개 검사 통과. 실제 앱의 구매·장착·해제·재접속을 로컬 합성 계정으로 확인했다. 브라우저에서 90/90 스킬, 270/270 이미지 프레임, 실제 전투 렌더러의 6직업 1~5차 교체 30/30을 확인했다.

별도 오래된 통합 테스트의 `STARS_REQUIRED` 기대와 아레나 상대 목록 문구 기대는 변경 전 코드에서도 현재 동작과 맞지 않는다. 해당 기존 테스트나 게임 규칙은 이 작업에서 변경하지 않았다.
