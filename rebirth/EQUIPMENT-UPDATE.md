# 직업별 장비 개편

- 5직업 각각 무기 3종, 9개 장착 부위 유지. 동일 레벨·강화 기준 기존 능력치 유지.
- 전사: 검/도끼/창, 마법사: 지팡이/마도서/완드, 궁수: 활/석궁/장궁, 도적: 단검/아대/쌍검, 해적: 권총/너클/대포.
- 일반 Lv.1~180 550종, 보스 Lv.20~200 550종, 총 1,100종. 각 조합에 별도 이름과 그림 셀을 연결.
- 직업별 일반/보스 이미지 10장 생성. 각 부위를 독립 행으로 매핑해 동일 레벨을 맞춤 외형 세트로 만들지 않음. 기존 보스 세트 능력치는 유지.
- 장비에 weaponVariant 추가. 기존 장비와 도감 키는 기본 종류(0)로 호환. 다른 종류는 별도 도감/보관함 키.
- 서버 드롭과 선택 제작, 거래 구매 도감, 복구 및 이전의 무기 종류 판정에 반영.
- 일반 사냥 정산 30초, 오프라인 최대 6시간, 기존 확률·강화 비용 유지.
- Supabase ringu-rebirth v5 및 rebirth_weapon_variant_collection 반영.
- 사용자 요청에 따라 테스트·시뮬레이션·브라우저 검증은 실행하지 않음.

그림 제작: built-in image generation. 공통 프롬프트는 11열×10행의 직업별 게임 장비 아이콘, 열 순서 무기 3종/투구/갑옷/바지/장갑/신발/반지/귀걸이/펜던트, 각 아이콘 고유 형태·소재·색·장식, 텍스트와 인물 제외. 일반과 보스 별도 생성. 도적 일반 시트의 추가 장화 열은 매핑에서 제외.
