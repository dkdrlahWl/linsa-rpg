Generated with the built-in ImageGen tool, then copied into the project. Final file: `second-sequence-atlas-v1.png`. No external image service or downloaded art was used.

## Generation prompt

Use case: stylized-concept. Asset type: production sprite atlas for a polished Korean fantasy top-down action RPG. Create one precisely aligned 5-column by 3-row sprite atlas, 1536x1024. Every cell has equal dimensions and one centered isolated luminous effect. No frames, labels, typography, scenery or characters. Columns left to right: warrior (ember red/gold), mage (cyan/violet crystal), archer (jade/ivory), rogue (violet/crimson), pirate (amber/teal). Row 1: crescent greatsword energy slash; ring of eight floating crystalline spears; ornate hawk-shaped arrowhead and aiming halo; crossed spectral daggers with shadow ribbons; ornate flintlock muzzle with sparks. Row 2: sweeping blade; crystalline lance pointing right; radiant arrow pointing right; diagonal twin-dagger X slash; fiery shell pointing right. Row 3: rock-and-sword eruption; prismatic crystal shatter; piercing starburst; double crescent X explosion; gunpowder burst with teal smoke. Detailed hand-painted 2D fantasy VFX, sharp silhouettes, bright cores, tapered trails and delicate fragments. Keep every motif within its cell with generous padding.

## Final correction prompt

Replace the entire broad colored background with PERFECT FLAT PURE BLACK #000000. Absolutely no background gradients. Keep the fifteen luminous fantasy VFX objects in exactly the same 5 columns x 3 rows positions, but shrink each motif slightly to fit comfortably within its equal grid cell with at least 12% black padding on every edge. The empty spaces, boundaries and gaps must be solid black. Only the actual slash, spear, arrow, daggers, gunshot, and impact fragments may emit light. Preserve all detailed sprite designs and class colors, reduce sprawling ambient glow. No labels or borders. This will be used with additive screen blending in a game, so empty pixels must be BLACK. 1536x1024.

An intermediate transparent-background request did not produce usable alpha; the final black-backed sheet is deliberately rendered with screen blending.
