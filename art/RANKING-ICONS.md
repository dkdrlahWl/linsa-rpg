# Ranking presentation icons (RK1)

Crown, dragon, compass and chess-rook vector paths: Font Awesome Free by Fonticons, Inc.
Source: https://fontawesome.com/
License for SVG icons: Creative Commons Attribution 4.0 International (CC BY 4.0).
License: https://creativecommons.org/licenses/by/4.0/
Paths are embedded in ranking-ui.js, colored and resized for the interface. No icon font is distributed.
The crossed-sword and laurel decorations are custom vector markup.
The existing citadel-stage-v1.webp artwork is reused as a decorative background.
Player names, scores, floor numbers, UID and controls are live HTML, not embedded in an image.
