# 협동 균열 · 잠재 해금 업데이트

- Lv.20/40/60/80/100/120/140/160/180/200, 총 10개 균열.
- 1–4인 입장, 3인 기준 고정 체력·공격력. 전투 제한 90초, 입장과 보상 횟수 무제한.
- 직접 피해를 준 참가자마다 개인 상자 1개. 승리 후 이동 가능하며, 상자에서 180 이내로 접근해서 공격 또는 상자 버튼으로 개봉하면 보상을 받고 혼자 퇴장한다. 미수령 파티원의 상자는 남는다. 처치에 참여하고 쓰러진 참가자는 상자를 수령할 수 있도록 일어난다.
- 새 장비는 잠재 3줄이 잠긴 상태. 잠재 해금 주문서 1개로 3줄을 모두 레어 등급으로 해금한다(성공 100%). 그 뒤 큐브 사용 가능. 기존 개방 장비의 잠재와 보유 강화는 유지한다.
- 주문서는 재료 가방에 보관하며 유저 간 거래 가능. 확장석은 복구하지 않는다.

## 개인 상자 1개당 독립 추첨

|던전 레벨|레드 1개|블랙 1개|프라임 1개|장비 1개|파편|잠재 주문서 1개|
|---|---:|---:|---:|---:|---:|---:|
|20·40·60|1%|0%|0%|2%|8%로 1개|1%|
|80·100·120|2%|0.3%|0%|3%|12%로 2개|1.5%|
|140·160·180·200|3%|0.6%|0.1%|4%|16%로 3개|2%|

확정 골드: 레벨 순서대로 260 / 420 / 580 / 740 / 900 / 1,060 / 1,220 / 1,380 / 1,540 / 1,700 G.
각 항목은 독립 추첨한다. 장비는 던전과 같은 레벨의 일반 장비로, 5직업 각 20%, 9부위 각 1/9, 일반 디자인 2종 각 50%다. 파티원끼리 보상을 나누지 않는다.

## 검증

- 로컬 PostgreSQL에서 4인 제한, 처치 직후 보상 미지급, 개인별 수령/퇴장, 동일 요청 재전송, 거리·기여도 조건, 일반 계정의 보상 RPC 직접 호출 차단 확인.
- 신규 잠재 잠금, 1개 소비로 전체 해금, 재사용 차단, 기존 잠재 보존, 10개 레벨 장비 생성 확인.
- 390px 모바일과 1280px 화면에서 상자 개봉 버튼, 잠재 주문서 화면, 가로 넘침과 브라우저 오류 확인.
- 같은 레벨 일반 장비 9부위, 20–60은 5성·레어, 80–120은 10성·에픽, 140–200은 15성·유니크 기준. 전사·마법사·궁수 3인이 피격 없이 계속 공격한 계산은 약 53–66초. 실제 시간은 장비 옵션·파티 구성·회피와 이동에 따라 달라진다.
