# 장비 표시·제작 상세 개선

- 균등 격자로 잘라 보이던 장비를 실제 픽셀 경계에 맞춰 표시합니다. 투명 원본은 장비 본체의 연결 영역으로 만든 SVG 클립을 사용해 인접 장비 조각을 제외합니다.
- 이미지 데이터에 `bytes omitted` 문구가 들어가 깨진 전사 일반/보스, 마법사 보스, 궁수 보스, 200레벨 일반 시트를 새 PNG로 교체합니다. 정상 원본은 내장 WebP를 손실 없이 별도 파일로 추출했습니다.
- 보스 재료 10종 아틀라스를 새로 생성하고 재료함 및 제작 비용에 연결했습니다.
- 제작 부위 선택 시 이름, 그림, 기본 능력치, 보유/필요 재료, 제작 조건을 표시합니다. 상세 보기에는 장비 교체 시 공격력/HP와 세트 효과, 장착 레벨 안내가 있습니다.
- 서버 제작 규칙과 상태 형식은 그대로 사용합니다. 360px/1280px 로컬 화면에서 선택 변경, 상세 보기, 창 제작 및 재료 차감, 가로 넘침 없음, 브라우저 오류 없음을 확인했습니다. 실제 계정 재료는 사용하지 않았습니다.

이미지 제작: built-in image generation. 신규 PNG는 `rebirth/equipment/*-v2.png`; 좌표·클립은 `equipment-bounds.mjs`에 있습니다. 기존 SVG는 이전 버전 캐시 호환을 위해 남겨 두었습니다.
