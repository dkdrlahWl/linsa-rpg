# 1·2차 스킬 개편

기존 1차 버프와 숨은 6% 회복을 제거하고, 기존 2차의 공격 외형을 1차로 이동했다. 1차와 새 2차는 서로 다른 그림을 사용한다.

| 직업 | 1차 | 총 피해 / 재사용 | 새 2차 | 타격 / 시간 / 총 피해 / 재사용 |
|---|---|---|---|---|
| 전사 | 대지 분쇄 | 160% / 10초 | 균열 참격 | 8타 / 3초 / 470% / 14초 |
| 마법사 | 빙결 폭쇄 | 180% / 12초 | 프리즘 창 | 9타 / 3.8초 / 480% / 16초 |
| 궁수 | 질풍 관통 | 175% / 11초 | 매의 저격 | 10타 / 3.4초 / 460% / 15초 |
| 도적 | 그림자 처형 | 160% / 10초 | 잔영 교차 | 10타 / 2.8초 / 470% / 14초 |
| 해적 | 파쇄 포격 | 170% / 11초 | 산탄 폭발 | 8~10타 / 3.6초 / 420~480% / 15초 |

1차는 Lv.30, 2차는 Lv.60 전직 후 해금된다. 도적 1차는 기존 치명 확률 +5%p를 유지한다. 피해 수치는 전 타격 적중 시 계수이며 치명타·보스 피해가 별도로 적용된다.

`combat-skills.mjs`의 동일한 결정적 타임라인을 일반 보스, 탑, 협동, 웨이브가 사용한다. 발사 시각과 피해 시각을 따로 기록해 투사체 도착과 피해가 일치한다. 이동·회피·다른 스킬은 계속 사용할 수 있다. 궁수는 고정 직선, 전사는 균열 경로, 도적은 고정 교차 영역, 마법사·해적은 각 탄환 발사 시 표적 위치를 사용한다. 해적의 측면 탄환 두 발은 시전자 기준 440 이내에서만 적중하며 멀리서는 옆으로 빗나간다.

1차는 기존 `second-job-atlas.webp`와 직업별 기존 공격 그림을 사용한다. 새 2차는 `tower/second-sequence-atlas-v1.png`의 전용 5×3 그림을 사용하고, 화면 합성·곡선 궤적·균열·실제 도적 잔영·충격파·파편을 함께 그린다. 검정 배경은 screen 합성으로 제거한다. 원본은 내장 ImageGen으로 제작했으며 제작 프롬프트는 같은 폴더의 `.prompt.md`에 기록했다.

`skills-preview.html`에서 다섯 직업의 1·2차를 비교할 수 있다. 실제 계정 데이터에는 접근하지 않는다.

검증: `skill-sequence.test.mjs`, `skills-v2.test.mjs`, 전직·협동 재생·웨이브·오디오 테스트, `skill-visual.browser.test.mjs`의 데스크톱/모바일 및 실제 조작 화면.

통합 검증: 최신 2인 전직전의 배우 상태에도 firstCast/secondCast를 보존하며, trial-coop.test.mjs에서 전 직업·4개 전직 시험이 단독전과 동일한 피해·시간을 갖는지 통과했다. 웨이브의 3개 표적에도 타격마다 정확히 한 번씩 피해가 적용된다.

기존 engine.test.mjs는 이번 변경 전 origin/main에서도 사냥터 별 제한(STARS_REQUIRED)을 기대하는 13행에서 실패한다. 본 변경과 무관한 기존 테스트 조건 불일치이며 해당 제한을 되돌리지는 않았다.
