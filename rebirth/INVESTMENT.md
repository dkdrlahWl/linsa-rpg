# 골드 코인 투자

상단 투자 메뉴. 도현·링구·원재·민정·지원·민지·성민·예찬 8개 코인, 시작 1개 10,000골드. 정수 수량만 거래하며 코인을 구매하여 보유하고 판매할 수 있다. 숏 주문은 서버에서도 거부한다. 배율 1배, 진입 수수료 없음, 판매 시 정산액 1%를 올림 차감한 뒤 정수 골드를 지급한다. 투자금은 보유 골드 안에서 자유롭게 설정한다.

가격은 서버의 공통 시장이며 매시 정각 갱신한다. 시간당 최대 ±5%, 한국 시간 자정 기준 ±30%. 한도에 닿으면 자정까지 가격 고정, 자정에는 가격 유지·등락률 0% 초기화. 8개 모두 동일한 변동 폭을 쓰고 코인별 결과는 독립적이다. 화면에는 실제 생성된 시간봉 24개를 표시하고 꼬리는 없다. 첫 시간봉은 출시 다음 정각부터 생성된다. 상승 초록·하락 빨강. 수익률은 구매가 대비 현재가로 계산하며 판매 전 표시에는 수수료가 포함되지 않는다. 판매 예상 수령액을 별도로 표시한다. 

서버 SQL은 인증 세션 확인, 공유시장 잠금과 플레이어 행 잠금, 요청 영수증으로 중복 거래 방지, 잔액 확인, 진입/판매 시 화면 가격의 시간 경계 검증을 수행한다. 기존 게임의 revision을 증가시켜 다른 게임 저장과 충돌 시 재계산한다. 가격표·포지션은 private schema RLS와 테이블 권한 차단으로 보호한다. public RPC는 SECURITY INVOKER, 내부 함수는 세션 인증을 확인한다.

검증: PGlite 실제 SQL 거래/정산, 재전송, 타 계정 소유권, 잔액, 소수 수량 거절, 시간 경계, 72시간 한도, 숏 주문 거절. 모바일 360×800·412×915 및 데스크톱 1280×900 브라우저에서 8개 카드, 코인 구매, 판매, 가로 넘침과 JS 오류 확인.

속보: 한국 날짜별 전체 시장에 2~4건, 서로 다른 랜덤 분에 발표. 대상 코인과 호재/악재 및 100개씩의 제목을 서버에서 선택한다. 발표 시점부터 정확히 24시간 적용하고 자정에도 남은 효과는 유지한다. 기사 강도는 내부적으로 10~30%의 상대 확률 증가: 호재 10%면 기존 상승 사건 확률을 1.1배, 기본 상승 총확률 50%를 55%로 바꾸고 하락을 45%로 맞춘다. 악재는 반대. 같은 방향의 활성 기사는 합산하되 반대 방향 속보가 나오면 이전 방향 효과를 취소하고 총 상승 확률은 5~95% 범위로 제한한다. 변동 크기 분포는 유지하고 방향 추첨 가중치에 반영한다. 미발표 기사·발표 예정 시간·효과 수치는 RPC에서 제외한다. 매분 cron으로 스케줄을 유지한다. 일반 변동은 정각, 뉴스는 발표 즉시 해당 방향 3~11%로 한 번 반영한다. 뉴스도 하루 상·하한가에 닿으면 가격을 고정하고, 같은 시간봉의 종가만 갱신해 꼬리는 만들지 않는다. 구매·판매 주문은 시간과 가격을 함께 검사하여 뉴스 전 시세로 주문하지 못하게 한다.

2026-10-01 재시작: 열린 포지션을 전부 수수료 없이 원금 환급하고, 8개 가격과 오늘 기준가를 10,000G로 초기화하며 차트를 비웠다. 환급 내역은 판매 기록에 `초기화 환급`으로 남는다.

속보 알림: 투자 버튼과 속보 버튼에 미확인 기사 수를 같은 우편 배지로 표시한다. 모든 화면에서 30초 간격으로 시세 변경 없이 알림만 확인한다. 속보창을 열 때 실제 표시된 기사 ID만 읽음 처리하며, 계정별 서버 영수증으로 새로고침·기기 변경 후에도 유지한다. 미발표 기사는 조회하거나 읽음 처리할 수 없다. 읽지 않은 오래된 기사도 확인 전까지 수에 포함하고 목록은 미확인 기사를 우선 표시한다.

거래내역 버튼: 속보 왼쪽에 배치한다. 판매한 코인명, 수수료 차감 후 수령액에서 원금을 뺀 실현 수익·손실 G와 원금 대비 %를 표시하며 환급은 별도로 표기한다. 속보와 거래내역은 7개 행이 보이는 목록에서 아래로 내려 이전 기록을 불러온다. 날짜와 UUID를 함께 쓰는 커서로 동일 시각 거래도 중복·누락 없이 조회하고 거래는 본인 기록만 반환한다.

거래내역 상단 합계는 전체 판매 기록을 계정별로 집계한다. 총 수익은 양수 실현손익의 합, 총 손실은 음수 실현손익의 절댓값 합, 총 PnL은 둘의 차이이며 모두 판매 수수료 반영 후다. 현재 페이지나 보유 코인의 미실현손익은 합계에 넣지 않는다.
속보는 하루 2~4개 랜덤 개수를 정한 뒤 하루를 같은 수의 구간으로 나누고 각 구간 내부에서 발표 분을 추첨한다. 구간 경계에 1시간씩 여유를 두어 정규 하루 스케줄의 발표 사이를 최소 2시간 벌린다. 오늘 미발표 기사도 개수와 ID를 유지한 채 남은 시간에 분산했다.
