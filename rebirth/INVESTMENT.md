# 골드 코인 투자

상단 투자 메뉴. 도현·링구·원재·민정·지원·민지·성민·예찬 8개 코인, 시작 1개 10,000골드. 정수 수량만 거래하며 코인별 롱·숏을 동시에 보유할 수 있다. 배율 1배, 진입 수수료 없음, 판매 시 정산액 1%를 올림 차감한 뒤 정수 골드를 지급한다. 투자금은 보유 골드 안에서 자유롭게 설정한다.

가격은 서버의 공통 시장이며 매시 정각 갱신한다. 시간당 최대 ±5%, 한국 시간 자정 기준 ±30%. 한도에 닿으면 자정까지 가격 고정, 자정에는 가격 유지·등락률 0% 초기화. 8개 모두 동일한 변동 폭을 쓰고 코인별 결과는 독립적이다. 화면에는 실제 생성된 시간봉 24개를 표시하고 꼬리는 없다. 첫 시간봉은 출시 다음 정각부터 생성된다. 상승 초록·하락 빨강. 수익률은 진입가 대비 롱/숏 방향으로 계산하며 판매 전 표시에는 수수료가 포함되지 않는다. 판매 예상 수령액을 별도로 표시한다. 숏 전액 손실은 자동 청산하고 가방 골드에 추가 손실을 청구하지 않는다.

서버 SQL은 인증 세션 확인, 공유시장 잠금과 플레이어 행 잠금, 요청 영수증으로 중복 거래 방지, 잔액 확인, 진입/판매 시 화면 가격의 시간 경계 검증을 수행한다. 기존 게임의 revision을 증가시켜 다른 게임 저장과 충돌 시 재계산한다. 가격표·포지션은 private schema RLS와 테이블 권한 차단으로 보호한다. public RPC는 SECURITY INVOKER, 내부 함수는 세션 인증을 확인한다.

검증: PGlite 실제 SQL 거래/정산, 재전송, 타 계정 소유권, 잔액, 소수 수량 거절, 시간 경계, 72시간 한도, 숏 청산. 모바일 360×800·412×915 및 데스크톱 1280×900 브라우저에서 8개 카드, 롱/숏 투자, 판매, 가로 넘침과 JS 오류 확인.

속보: 한국 날짜별 전체 시장에 2~4건, 서로 다른 랜덤 분에 발표. 대상 코인과 호재/악재 및 100개씩의 제목을 서버에서 선택한다. 발표 시점부터 정확히 24시간 적용하고 자정에도 남은 효과는 유지한다. 기사 강도는 내부적으로 10~30%의 상대 확률 증가: 호재 10%면 기존 상승 사건 확률을 1.1배, 기본 상승 총확률 50%를 55%로 바꾸고 하락을 45%로 맞춘다. 악재는 반대. 겹치는 기사는 부호를 포함해 합산하고 총 상승 확률은 5~95% 범위로 제한한다. 변동 크기 분포는 유지하고 방향 추첨 가중치에 반영한다. 미발표 기사·발표 예정 시간·효과 수치는 RPC에서 제외한다. 매분 cron으로 스케줄을 유지하되 가격은 정각에만 변경한다.

2026-10-01 재시작: 열린 포지션을 전부 수수료 없이 원금 환급하고, 8개 가격과 오늘 기준가를 10,000G로 초기화하며 차트를 비웠다. 환급 내역은 판매 기록에 `초기화 환급`으로 남는다.
